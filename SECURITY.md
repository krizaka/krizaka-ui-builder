# Security policy

**Please do not report vulnerabilities in public issues.**

Use GitHub's private vulnerability reporting: on this repository, open **Security → Report a vulnerability**. If that is not
possible, write to us through the [Krizaka contact form](https://www.krizaka.com/en/contact) without technical details, and we
will open a private channel. The organisation-wide policy is in
[krizaka/.github](https://github.com/krizaka/.github/blob/main/SECURITY.md).

We acknowledge reports within two business days, keep you informed while we fix, and credit you in the advisory unless you
prefer otherwise. Supported versions: the latest release and `main`.

## Upstream fixes

Krizaka UI Builder is a fork of Puck (MIT). When the upstream project publishes a security fix, we cherry-pick it into this
fork within 7 days of the advisory. Report a vulnerability in this fork to Krizaka as above, not to the upstream project: we
forward what concerns upstream code.
